# 🚗 UK Road Accident Analysis Dashboard | Power BI

## 📌 Project Overview

The UK Road Accident Analysis Dashboard is an interactive Power BI project designed to analyze road accident data across the United Kingdom.

The dashboard provides insights into accident casualties, vehicle types, accident severity, road surface conditions, junction types, district-wise accident distribution and yearly accident trends.

The objective is to identify accident patterns and understand the factors associated with road accidents through interactive data visualizations.

## 🎯 Project Objectives

- Analyze total road accident casualties.
- Identify accidents by vehicle type.
- Understand accident trends across different quarters.
- Analyze casualties based on the number of vehicles involved.
- Identify districts with higher accident counts.
- Analyze accidents based on road surface conditions.
- Understand accident distribution across junction types.
- Evaluate police force investigation involvement.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard development and visualization.
- **Power Query** – Data transformation.
- **DAX** – KPI calculations and measures.
